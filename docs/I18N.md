# Internationalization (i18n)

Tato aplikace je vícejazyčná s podporou českého, anglického a německého jazyka.

## Struktura

- **`UI/src/lib/i18n/index.js`** - Hlavní i18n modul s překladovými klíči
- **`UI/src/lib/config/surveyjs.js`** - Konfigurace verzí SurveyJS a jazyků

## Jazyk aplikace

Jazyk se automaticky detekuje podle jazyka prohlížeče. Uživatel může jazyk změnit v hlavičce aplikace pomocí přepínače jazyků (CS/EN/DE). Vybraný jazyk se ukládá do `localStorage`.

## Jak přidat nové překlady

Když přidáváte nový text do UI, postupujte takto:

1. **Přidejte překlad do `UI/src/lib/i18n/index.js`**

   Do objektu `translations` přidejte klíč a překlady pro všechny jazyky:

   ```javascript
   const translations = {
     en: {
       'myFeature.newText': 'My new text',
       // ...
     },
     cs: {
       'myFeature.newText': 'Můj nový text',
       // ...
     },
     de: {
       'myFeature.newText': 'Mein neuer Text',
       // ...
     }
   };
   ```

2. **Použijte v komponentě**

   ```svelte
   <script>
     import { translations_store } from '$lib/i18n/index.js';
     $: t = $translations_store;
   </script>

   <h1>{t('myFeature.newText')}</h1>
   ```

## Jak aktualizovat SurveyJS verze

Když vyjde nová verze SurveyJS:

1. **Zkontrolujte nejnovější verzi na npm**
   
   Navštivte: https://www.npmjs.com/package/survey-core
   
   Nebo spusťte:
   ```bash
   npm view survey-core versions --json
   ```

2. **Aktualizujte seznam v `UI/src/lib/config/surveyjs.js`**

   Přidejte novou verzi na začátek pole `SURVEYJS_VERSIONS`:

   ```javascript
   export const SURVEYJS_VERSIONS = [
     { value: '1.12.9', label: '1.12.9 (Latest Stable)', isLatest: true, isProduction: true },
     { value: '1.12.8', label: '1.12.8', isLatest: false, isProduction: true },
     // ...
   ];
   ```

   **Důležité:**
   - Nastavte `isLatest: true` pouze pro nejnovější produkční verzi
   - Ostatní verze by měly mít `isLatest: false`
   - `isProduction: true` pro stabilní verze určené pro produkci
   - `isProduction: false` pro legacy nebo experimentální verze

3. **Není nutné nic rebuildit**
   
   Změny se projeví okamžitě při dalším načtení stránky.

## Jazyky formulářů

Aplikace podporuje tři jazyky pro formuláře:
- **cs** - Čeština 🇨🇿
- **en** - English 🇬🇧
- **de** - Deutsch 🇩🇪

Při vytváření formuláře můžete vybrat více jazyků pomocí multiple select.

## Konvence pro překlady

- Používejte strukturované klíče s tečkou: `section.key`
- Obecné texty: `common.*` (save, cancel, delete, etc.)
- Specifické pro feature: `forms.*`, `campaigns.*`, atd.
- Autentizace: `auth.*`

## Testování překladů

1. Přepněte jazyk v UI pomocí přepínače CS/EN/DE
2. Zkontrolujte všechny stránky a formuláře
3. Ověřte, že žádný text není v původním anglickém znění (kromě technických ID a kódů)
4. Otevřete konzoli prohlížeče - pokud vidíte přeložený text jako klíč (např. "forms.title" místo "Forms"), překlad chybí

## Přidání nového jazyka

1. Přidejte jazyk do `languages` objektu v `UI/src/lib/i18n/index.js`
2. Přidejte kompletní sadu překladů do `translations` objektu
3. Přidejte jazyk do `FORM_LANGUAGES` v `UI/src/lib/config/surveyjs.js`
